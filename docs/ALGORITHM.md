## 一、會用到的技術指標

| 指標 | 白話解釋 | 參數 |
| --- | --- | --- |
| **MA**（移動平均） | 過去 N 天收盤價的平均。MA20 ≈ 月線、MA60 ≈ 季線 | 5 / 20 / 60 |
| **RSI**（相對強弱） | 最近「漲的力道 vs 跌的力道」，0–100。>70 超買、<30 超賣 | 14（Wilder 平滑，與 TradingView 相同） |
| **布林通道** | 中軌 = MA20，上下軌 = 中軌 ± 2 個標準差。約 95% 的價格會落在通道內 | 20, 2σ |
| **%B** | 價格在通道中的位置：0 = 下軌、0.5 = 中軌、1 = 上軌 | — |
| **ATR**（平均真實波幅） | 這檔股票「平常一天會波動幾塊錢」 | 14 |

> 💡 **為什麼停損要用 ATR，不用固定 −5%？**
> 台積電一天波動 1.5% 很正常，特斯拉一天波動 4% 也很正常。固定 −5% 對特斯拉太緊（很容易被洗出場），對台積電又太鬆。ATR 讓停損距離自動貼合每檔股票的「個性」。

## 二、價位計算：Buy Zone / Take Profit / Stop Loss

```
buy_zone_high = (布林下軌 + 中軌) / 2          ← 回到通道「下半部」才考慮買
buy_zone_low  = 布林下軌 − 0.5 × ATR           ← 容許稍微跌破下軌（常見的假跌破）
entry_ref     = (buy_zone_low + buy_zone_high) / 2   ← 參考進場價（買進區中點）
stop_loss     = buy_zone_low − 1 × ATR         ← 再留一天的波動當緩衝
risk          = entry_ref − stop_loss
take_profit   = max(布林上軌, entry_ref + 2 × risk)  ← 目標至少是風險的 2 倍
risk_reward   = (take_profit − entry_ref) / risk     ← 風報比，設計上一定 ≥ 2
trailing_stop = 近 22 根最高價 − 3 × ATR       ← 吊燈停損，給「已經持有」的人用
```

**兩種停損的差別：**

- `stop_loss`（停損 SL）：給「打算在買進區進場」的人。從買進區往下算。
- `trailing_stop`（移動停損）：給「已經抱著股票」的人。股價創新高，停損也跟著往上移，鎖住獲利。收盤跌破它，卡片上會出現警示。

### 實際算一次 🧮

假設某檔股票今天：收盤 **960**、布林下軌 **940**、中軌 **1,000**、上軌 **1,060**、ATR **20**、近 22 日最高 **1,010**。

| 項目 | 計算 | 結果 |
| --- | --- | --- |
| 買進區上緣 | (940 + 1000) / 2 | **970** |
| 買進區下緣 | 940 − 0.5 × 20 | **930** |
| 參考進場價 | (930 + 970) / 2 | 950 |
| 停損 SL | 930 − 20 | **910** |
| 風險 | 950 − 910 | 40 |
| 停利 TP | max(1060, 950 + 2×40 = 1030) | **1,060** |
| 風報比 | (1060 − 950) / 40 | **2.75 : 1** |
| 移動停損 | 1010 − 3 × 20 | **950** |
| 現價位置 | 930 ≤ 960 ≤ 970 | ✅ **位於買進區** |

## 三、訊號分數 → 買進 / 賣出建議

每一項給分，加總後決定建議：

| 項目 | 條件 → 分數 |
| --- | --- |
| RSI | < 30 **+2**（超賣）· < 40 **+1** · > 60 **−1** · > 70 **−2**（超買） |
| %B | < 0 **+2**（跌破下軌）· < 0.2 **+1** · > 0.8 **−1** · > 1 **−2**（突破上軌） |
| 均線趨勢 | 收盤 > MA60 且 MA20 > MA60（多頭排列）**+1**；兩者皆 < MA60（空頭排列）**−1** |
| 新聞情緒 | 情緒分數（−1 ~ +1）× 2 → **−2 ~ +2** |

| 總分 | 建議 |
| --- | --- |
| ≥ 4 | 強力買進 STRONG_BUY |
| ≥ 2 | 買進 BUY |
| −2 < 分數 < 2 | 觀望 HOLD |
| ≤ −2 | 賣出 SELL |
| ≤ −4 | 強力賣出 STRONG_SELL |

**延續上面的例子**：RSI = 35（+1）、%B = (960−940)/(1060−940) = 0.17（+1）、多頭排列（+1）、新聞情緒 +0.4（+0.8）
→ 總分 **3.8 → 買進 BUY**，而且現價剛好在買進區內。

**設計理念：**「多頭趨勢中的拉回」是勝率較高的買點——RSI 和 %B 低（便宜）＋ 趨勢向上（方向對）→ 分數高。漲過頭時（RSI > 70、突破上軌）分數變負，提醒停利。

**K 線圖上的 B / S 標記**：整段歷史用同一套技術面分數（不含新聞，因為歷史新聞資料不齊全）算一遍，分數「由下往上穿過 +2」標 **B**、「由上往下穿過 −2」標 **S**。同方向至少間隔 5 根 K 棒，避免畫面密密麻麻。

## 四、新聞情緒分析

### Step 0：從哪裡抓、只留可信來源

4 個來源平行抓取（任何一個失敗都不影響其他）：Yahoo Finance、Google News RSS、證交所重大訊息（.TW）、Finnhub（美股，選用）。
接著只保留**可信媒體白名單**裡的發布者（`services/news_sources.py`），並分級：

| 等級 | 範例 | 重要性加分 |
| --- | --- | --- |
| 官方公告 official | 公開資訊觀測站 | +0.8 |
| 主流媒體 major | Reuters、Bloomberg、中央社、經濟日報、鉅亨網… | +0.3 |
| 公司新聞稿 press_release | Business Wire、PR Newswire | +0.2 |

同一則新聞被多家轉載（網址不同、標題相同）→ 只留等級最高的那一筆，避免同一件事被重複計分。

### Step 1：單則新聞打分數（規則式 NLP）

用一份**金融情緒詞典**（中英文都有）比對標題，每個詞有權重：

| 英文範例 | 權重 | 中文範例 | 權重 |
| --- | --- | --- | --- |
| raises guidance | +1.5 | 漲停 | +1.5 |
| beats estimates | +1.4 | 優於預期 | +1.3 |
| upgrade | +1.2 | 上修 / 利多 | +1.2 |
| downgrade | −1.2 | 下修 / 利空 | −1.2 |
| cuts guidance | −1.5 | 砍單 | −1.2 |
| bankruptcy | −2.0 | 跌停 | −1.5 |

處理細節：

1. **片語優先**：`beats estimates` 命中後，不會再額外算一次 `beat`。
2. **否定詞反轉**：英文看前 3 個字有沒有 not / no / never；中文看前 2 個字有沒有「不 / 未 / 沒 / 無」。
   本身就含否定的詞（如「不如預期」）不會被再反轉一次。
3. **壓縮到 −1 ~ +1**：`score = tanh(原始總分 / 2)`，一則標題命中很多詞也不會爆表。
4. **標籤**：> 0.15 = Bullish、< −0.15 = Bearish、其餘 Neutral。

實際輸出（直接執行程式得到的結果）：

| 標題 | 命中 | 分數 | 標籤 |
| --- | --- | --- | --- |
| Nvidia beats estimates, raises guidance | beats estimates、raises guidance | +0.90 | Bullish |
| Tesla shares plunge after analyst downgrade | downgrade、plunge | −0.83 | Bearish |
| Company did not beat expectations | beat（被 not 反轉） | −0.46 | Bearish |
| 台積電營收創新高，法人看好 | 創新高、看好 | +0.72 | Bullish |
| 市場不看好鴻海新產品 | 看好（被「不」反轉） | −0.38 | Bearish |
| 聯發科財測下修，外資賣超 | 下修、賣超 | −0.76 | Bearish |

### Step 2：挑出 Big News

`重要性 = |情緒分數| + (是重大事件 ? 1 : 0) + 來源等級加分`

重大事件關鍵字：earnings、guidance、acquisition、FDA、lawsuit、財報、營收、法說會、併購、股利、關稅…
近 48 小時內重要性最高的 **6 則**，就是這檔股票的「Big News」。

### Step 3：整體情緒 = 時間加權平均

越新的新聞越重要，半衰期 24 小時：`權重 = 0.5 ^ (經過小時 / 24)`

| 新聞 | 分數 | 幾小時前 | 權重 |
| --- | --- | --- | --- |
| A | +0.9 | 2 | 0.944 |
| B | −0.6 | 30 | 0.420 |
| C | +0.2 | 10 | 0.749 |

整體 = (0.9×0.944 − 0.6×0.420 + 0.2×0.749) / (0.944 + 0.420 + 0.749) = **+0.35 → Bullish**

### Step 4：產生 2 句摘要

| 模式 | 什麼時候 | 產出 |
| --- | --- | --- |
| **Claude AI**（`method: "llm"`） | `.env` 有設定 `ANTHROPIC_API_KEY` | 第 1 句：新聞重點；第 2 句：可能的短線影響。用 JSON Schema 固定格式 |
| **規則式**（`method: "rule"`） | 沒設定 Key，或 AI 呼叫失敗 | 模板：「X 近期共 N 則重點新聞，整體情緒偏多（+0.35），焦點為「…」。」+ 依標籤選一句影響評估 |

省錢設計：新聞組合（URL 雜湊）跟上一小時一樣 → 不重新呼叫 AI。

## 五、可以怎麼改進？（給你練習的方向）

1. **回測**：用 `signal_snapshots` 算「BUY 訊號後 5 / 20 天的報酬率」，看看哪些參數比較準。
2. **調參數**：RSI 門檻、布林 2σ、ATR 倍數都放在 `signals.py` 最上面，改了跑 `pytest` 確認沒壞。
3. **加入成交量**：放量突破 vs 量縮整理，是很常見的濾網。
4. **擴充詞典**：把你常看的財經新聞用語加進 `sentiment.py` 的 `ZH_POSITIVE` / `ZH_NEGATIVE`。
5. **大盤濾網**：加權指數（`^TWII`）或 S&P 500（`^GSPC`）在季線下時，所有買進訊號打折。
